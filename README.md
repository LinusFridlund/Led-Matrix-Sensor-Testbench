# Led Matrix Sensor Testbench
A modular testbench for interactive sensor fusion and signal processing demos. Built around a 32x64 pixel LED matrix, it uses an ESP32 S3 microcontroller and various sensors to make for a flexible platform to experiment with signal processing and fusion in a real senario.

## Overview
This project started as I wanted to build a project with sensor data processing in the real world. Instead of being stuck with making something on the computer with a downloaded dataset, I wanted to use real live data being processed in real time. The scope then grew to include a variety of sensors which can be used to create interactive real time demos. Rather than being a single fixed application, the firmware is built around selectable modes which each demonstrate a different DSP/fusion concept on the same hardware.
